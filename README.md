PWM Signal Generation and Monitoring System

Overview

Developed as part of ECE 355 – Microprocessor-Based Systems at the University of Victoria.

This project uses an STM32F051R8T6 microcontroller to control and monitor a PWM signal generated by an external NE555 timer circuit.

A potentiometer controls the signal through an ADC, DAC, and 4N35 optocoupler. The microcontroller also measures signal frequency and displays the results on an SSD1306 OLED.

Hardware

STM32F0 Discovery Board

NE555 Timer

4N35 Optocoupler

PBMCUSLK Expansion Board

Potentiometer

SSD1306 OLED Display

Key Features

ADC: Reads potentiometer voltage and calculates resistance.

DAC: Generates an analog output to control the optocoupler.

EXTI: Handles button presses and signal edge detection.

TIM2: Measures input signal frequency.

TIM3: Provides timing for OLED initialization (3 ms overflow) and periodic OLED refreshes (100 ms overflow).

SPI: Communicates with the OLED display.

NVIC: Manages external interrupts.

Project Structure

src/main.c – Initializes peripherals and coordinates the system.

src/include – Header files containing peripheral initialization functions for GPIO, TIM, ADC, DAC, and EXTI.
